# Open Minimalist Modules

## OMIMO

Open Minimalist Modules

OMIMO 是面向项目生态系统的一系列方法和模型。所有模块都经过精心设计，力求易于学习、易于使用和易于教学。

[CC](#footer-legal-info)

## 开放

所有 OMIMO 模块都是开放且自由的，并采用 Creative Commons Attribution（知识共享署名）许可。这意味着您可以以任何方式使用它们，包括商业用途，而无需事先获得许可。

根据该许可，OMIMO 模块所赋予的自由在未来不会被撤销。

## 极简

所有 OMIMO 模块都是极简系统，也就是说，它们专注于最核心的内容，而不是构建一个庞大而臃肿的系统。极简主义使模块更容易学习、更容易使用，也更容易教授。

这些模块提供的是方法或模型，而不是杂乱无章的建议集合。

## 模块化

OMIMO 采用模块化设计，其所有组成部分都经过精心设计，能够独立于其他部分运行。因此，您不会被绑定在整个系统中，而是可以使用任意模块，并将其与 OMIMO 之外的内容结合使用。

OMIMO 是一项持续发展的事业，未来还会增加更多模块。

## 项目生态系统

OMIMO 是一个由多个模块组成的系列，每个模块都旨在解决不同类型的问题。不存在“最佳”模块；合适的选择取决于具体情况。与其选择最流行的模块类型，不如先明确你的主要问题，然后选择最能解决这些问题的模块。
