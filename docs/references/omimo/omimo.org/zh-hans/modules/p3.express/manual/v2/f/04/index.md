# 归档项目文件 :: P3.express

现在我们已接近项目尾声，该将所有项目文件归档了。

## 目标

这些文件应该存放于安全位置，以便今后授权给相关人员使用，届时他们可在自己的项目中使用这些资料，无需重复劳动。项目组合管理系统将来可能也需要查看这些信息，以便对过去的项目做更加细致的分析。

## 常见问题

请考虑以下重要事项：

- 如果可能，确保将文件存放于一处，不会到处分散。
- 确保文件为只读模式。
- 务必妥善设置备份系统，这样不会丢失文件。
- 务必将文件存放于安全位置，只有被授权人员才有访问权限。

除此以外，文件的常见问题是文字不够明确，只有经常接触这些文档的人员在恰当的时间和背景下，才能理解它们。因此，所有文档务必简明扼要，这样即使相关人员不熟悉项目确切背景，也能理解文档内容。内部干系人几个月以后也难以理解自己的文档，这很常见，因此以上策略也适用于长期项目。

## 原则

以下原则在本管理活动中起了重要作用：

- [NUP5:](../../../../../nupp/manual/v1/nup5/index.md) 先定目标，后行动
- [NUP6:](../../../../../nupp/manual/v1/nup6/index.md) 使用可重复的元素
