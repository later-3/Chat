# 进行重点沟通 :: P3.express

向所有团队成员发送信息，告诉他们在本月期间项目所取得的成绩，并对他们作出的贡献表示感谢。

## 目标

提醒大家始终专注于目标，而不要只注重单独的专业活动。正确沟通重点，有助于团队团结一致。

## 常见问题

牢记以下几点，帮助您避免最常见的问题：

- 重点传达取得的成绩，而不是已完成的工作。
- 信息要明确，避免流于空谈。
- 信息要简短，几行就好。

## 原则

以下原则在本管理活动中起了重要作用：

- [NUP3:](../../../../../nupp/manual/v1/nup3/index.md) 始终积极主动
- [NUP4:](../../../../../nupp/manual/v1/nup4/index.md) 细节决定成败
- [NUP5:](../../../../../nupp/manual/v1/nup5/index.md) 先定目标，后行动
