# 吸取教训并规划改进 :: P3.express

汇总满意度评估答卷后，邀请团队成员参加研讨会，以根据满意度评估结果规划改进措施，并分享他们在本月期间吸取的教训。将各项信息记录在 **跟进登记表** 中，并为每个改进事项的跟进活动分配一名管理员。

[跟进登记表模板](../../follow-up-register.ods)

## 目标

这个研讨会有两个目标：制订有效的改进计划和团队建设。

利用研讨会规划改进措施，而不是让您样样都自行规划，这样很有用，因为 [群体智慧](https://en.wikipedia.org/wiki/Wisdom_of_the_crowd) 可以帮助您更好地进行规划，您也会因此获得团队成员的积极支持。

## 常见问题

请考虑以下事项，从而避免这方面最常见的问题：

- 只有在妥善组织的研讨会上，您才能获得满意的结果。在主持研讨会过程中，可以运用一些技巧，例如 [德尔菲法](https://zh.wikipedia.org/wiki/%E5%BE%B7%E5%B0%94%E8%8F%B2%E6%B3%95) 。
- 如有可能，请匿名收集意见，确保参与者都能自由自在地表达想法。可以使用特定软件和应用程序来确保匿名，同时也加快流程。
- 避免让大家 [锚定](https://zh.wikipedia.org/wiki/%E9%8C%A8%E5%AE%9A%E6%95%88%E6%87%89) 一个或几个想法上，而要使用中立的框架来解决问题。

## 原则

以下原则在本管理活动中起了重要作用：

- [NUP2:](../../../../../nupp/manual/v1/nup2/index.md) 将精力和资源用在最重要的事情上
- [NUP3:](../../../../../nupp/manual/v1/nup3/index.md) 始终积极主动
- [NUP4:](../../../../../nupp/manual/v1/nup4/index.md) 细节决定成败
- [NUP5:](../../../../../nupp/manual/v1/nup5/index.md) 先定目标，后行动
