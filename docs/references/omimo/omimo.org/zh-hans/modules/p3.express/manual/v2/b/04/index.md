# 启动每月周期 :: P3.express

如果在 [B03](../03/index.md) 环节中已通过审批，那么该为每月周期开个启动会议了。

## 目标

本管理活动环节有两个目标：

- 团队建设
- 将下个月的规划通知干系人。

## 常见问题

不要只是枯燥乏味地讲话和检查下个月的计划，而要为大家带来良好的体验，因为本次会议上，团队建设更加重要。您可以召集整个团队（必要时加上外部干系人）来次徒步、野餐等，同时适当促使会议达成两个主要目标。

## 原则

以下原则在本管理活动中起了重要作用：

- [NUP4:](../../../../../nupp/manual/v1/nup4/index.md) 细节决定成败
- [NUP5:](../../../../../nupp/manual/v1/nup5/index.md) 先定目标，后行动
