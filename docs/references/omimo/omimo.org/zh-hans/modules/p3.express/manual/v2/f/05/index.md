# 庆祝！ :: P3.express

现在是时候为团队成员或整个组织举办庆祝会了。本管理活动结束后，项目团队也将解散。

## 目标

这是为未来项目而投入，它可以提醒团队，大家都是在为同一个目标而努力。

## 常见问题

确保活动有声有色，令人难忘，而不是冗长枯燥的公司报告会。

## 原则

以下原则在本管理活动中起了重要作用：

- [NUP5:](../../../../../nupp/manual/v1/nup5/index.md) 先定目标，后行动
