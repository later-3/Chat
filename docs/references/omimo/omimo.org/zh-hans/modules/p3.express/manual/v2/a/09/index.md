# 启动项目 :: P3.express

如果在 [A08](../08/index.md) 环节中，项目已经通过审批，那么现在该举办启动活动，邀请客户和供应商干系人共同启动项目了。

最好用一整天时间，在组织以外的场所开展这一活动。项目经理和其他所有管理团队成员（如有）应当协导活动，确保大家都能获得美好体验。

## 目标

这次会议的主要目标如下：

- 正式启动项目
- 让内部和外部干系人相互认识并建立联系
- 沟通有关项目的基本信息

## 常见问题

千万不要将启动活动办成只谈项目细节的会议，枯燥无味，要让它成为难忘的团建体验。

## 原则

以下原则在本管理活动中起了重要作用：

- [NUP4:](../../../../../nupp/manual/v1/nup4/index.md) 细节决定成败
- [NUP5:](../../../../../nupp/manual/v1/nup5/index.md) 先定目标，后行动
