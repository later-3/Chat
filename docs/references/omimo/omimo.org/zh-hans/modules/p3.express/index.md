# P3.express - minimalist portfolio management system

## 什么是P3.express?

P3.express是一套极简实用的项目管理系统。
容易上手，使用方便。

P3.express自由开放，遵循知识共享许可协议。

## 为什么选择P3.express？

因为，尽管有 PRINCE2 <sup>®</sup> 和 PMBOK <sup>®</sup> Guide 等基本系统的存在，但大多数项目都是凭直觉在运行，并未得到结构化项目管理系统的帮助。之所以这样，是因为基本标准虽然极具价值，但对于普通项目来说过于复杂。

想象一下使用Excel的人们。如果用编程语言来取代Excel会怎样？大多数人无法驾驭编程语言，因此等于没有了工具，尽管编程语言比Excel更强大。

基本项目管理系统都类似于编程语言，而项目管理人员最需要的则是像Excel一样的工具。P3.express正是这样一款大多数人都能使用的简单工具。

## P3.express的工作方式是怎样的？

P3.express 使用一套周期性系统来使活动更加简单而有规律。设有每月、每周和每天等周期，每个周期侧重管理活动的一个方面。

除周期外，开始时是项目启动活动组，结束时则安排项目结束活动组。

最后还有个项目后管理活动组：这是设置于项目完成后的一个周期，用以评估收益。

除了流程外，还配有 4 份管理文档并设置各种角色。

[在线手册](manual/v2/index.md) 中全面介绍了P3.express的工作方式。
