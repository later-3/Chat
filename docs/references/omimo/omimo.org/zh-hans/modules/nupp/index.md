# Nearly Universal Principles of Projects :: OMIMO

## 什么是 NUPP？

NUPP 是一组近乎通用的项目原则：无论我们采用何种方法论和方式，在所有项目中都值得遵循的原则。

## 为什么选择 NUPP？

因为我们为管理项目所做的一些事情，随着时间推移可能会在不知不觉中失去意义。之后，它们仍会持续消耗我们的精力，却无法产生任何成果。以原则为先的方法有助于降低这种风险，并保持项目管理活动的有效性和成果性。

## NUPP 如何运作？

使用 NUPP 很简单：将这 6 条原则的列表放在手边，每当你需要做出决策或进行重要行动时，就用这些原则进行检查，并确保其与所有原则都兼容。开始时可能需要一些时间，但最终你会越来越熟练，并能够自动地这样做。

## 项目生态系统

OMIMO 是一个由多个模块组成的系列，每个模块都旨在解决不同类型的问题。不存在“最佳”模块；合适的选择取决于具体情况。与其选择最流行的模块类型，不如先明确你的主要问题，然后选择最能解决这些问题的模块。
