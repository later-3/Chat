# OMIMO 简体中文资料归档与学习入口

## 1. 归档结论

本目录保存 OMIMO 在 2026-08-05 发布于官方简体中文 Sitemap 中的全部内容：

- 49 个简体中文页面，全部通过标题、来源 URL、正文长度、中文内容和错误页质量门。
- 49 个页面媒体文件；网页中的 SVG 全景图以内联源码保留。
- 3 个第一方可编辑模板：项目说明书 ODT、跟进登记表 ODS、运行登记表 ODS。
- 25,561 个中日韩统一表意文字字符，页面 Markdown 共 182,700 字节。
- 每页保留原始 URL、抓取时间、转换方式和本地媒体链接。
- 全部简体中文站内链接已经改成本地相对链接，可在仓库中离线浏览。

归档范围以官方 [`zh-hans/sitemap.xml`](https://omimo.org/zh-hans/sitemap.xml) 为唯一页面基线。该 Sitemap 当前只包含 OMIMO 总览、项目方法全景、NUPP 和 P3.express；P1/P4/P5、Compass 及公告等只有英文或其他语言的内容不属于本次“中文版”归档。页面中指向英文资料和外部站点的链接保留为远程链接。

## 2. 从哪里开始

1. 第一次阅读，从[学习入口](学习/00-学习入口.md)开始。
2. 想先看到全貌，阅读[OMIMO知识地图](学习/01-OMIMO知识地图.md)。
3. 要按节奏掌握，执行[八周学习计划](学习/02-八周学习计划.md)。
4. 要把方法用到真实事项中，填写[P3.express项目实践工作簿](学习/03-P3.express项目实践工作簿.md)。
5. 日常决策时使用[NUPP决策检查卡](学习/04-NUPP决策检查卡.md)。
6. 学完后完成[掌握度测验](学习/05-掌握度测验.md)，再查看[参考答案与评分标准](学习/06-参考答案与评分标准.md)。

完整原文入口见[归档索引](archive-index.md)，机器完整性证据见[`archive-manifest.json`](archive-manifest.json)。

## 4. 版权与署名

原始内容来自 [OMIMO — Open Minimalist Modules](https://omimo.org/zh-hans/)，由 OMIMO 发布，并在网站中声明采用 Creative Commons Attribution（CC BY）许可。归档页保留原始 URL 与抓取时间。

`学习/`中的材料是基于 OMIMO 中文内容编写的重组、摘要、练习和检查表，属于衍生学习材料；使用或再发布时应继续注明 OMIMO 原始来源，并说明内容经过重组或改写。

## 5. 刷新方式

```bash
uv run python scripts/archive_omimo_zh_hans.py --workers 1
```

脚本会：

1. 读取官方简体中文 Sitemap。
2. 跳过已经通过质量门的页面，抓取新增或缺失页面。
3. 下载页面媒体和3个官方模板。
4. 将中文站内链接改成本地相对链接。
5. 重新生成归档索引和SHA-256清单。

并发抓取会与 Chrome 调试端口复用产生竞争，因此稳定刷新默认建议使用单路执行。需要完整重抓时增加 `--force`。

## 6. 已知原站内容问题

归档按原站内容保真保存，不静默修正文义：

1. P3.express模块页的英文标题写成“minimalist portfolio management system”，但页面正文和整套手册均明确是项目管理系统。
2. C03“启动每周周期”的常见问题把风险应对规划链接到D02；D02正文是验收可交付成果，实际负责风险、问题和变更请求的是D01。学习材料按活动正文解释为D01，并在答案中显式说明。
3. 部分中文翻译存在空格、标点或用词不统一；归档页保留原文，学习材料使用统一表述。
4. 中文全景图会链接到尚无简体中文版本的英文模块；这些链接保留为远程链接，不伪造中文归档。

## 7. 使用边界

这是一份外部方法资料快照和学习材料，不自动成为 Chat 项目的正式治理方法、产品架构或交付计划。若未来要将 P3.express 或 NUPP 纳入 Chat 项目正式流程，仍需单独比较适用范围、现有治理合同与实施代价，并经过项目审核。
