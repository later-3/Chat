# OMIMO 学习入口

## 1. 你最终要掌握什么

学完后，你不只是能背出术语，而应能独立完成4件事：

1. **选择方法**：用4个维度判断一个项目管理资源是否适合当前环境。
2. **作出判断**：用NUPP六项原则检查计划、会议、文档、风险和决策是否仍服务项目目标。
3. **运行项目**：解释并执行P3.express的7个活动组、33项管理活动、主要角色和4类管理文档。
4. **复盘改进**：用一个真实或模拟项目证明自己能从启动、周期管理、结尾一直走到项目后收益评估。

## 2. 掌握等级

| 等级 | 可以做到什么 | 验收证据 |
|---|---|---|
| L1 识别 | 看见名词能说明它是什么、不是什么 | 不看资料复述4个选择维度、6项原则、7个活动组 |
| L2 解释 | 能说明每项活动的目的、输入和常见误区 | 完成知识地图复述和基础测验，得分不低于80% |
| L3 应用 | 能把方法剪裁到一个具体项目 | 完成项目说明、可交付成果导图、两个登记表和至少1个周期演练 |
| L4 迁移 | 能判断哪些部分适用、需要改造或不适用 | 完成结业答辩：解释自己的剪裁、风险及未采用项 |

本学习包的目标是让你达到 **L3**，并为L4建立判断基础。

## 4. 每周固定学习节奏

每周安排4次、每次45—60分钟：

1. **输入**：阅读指定原文，用自己的话写5—10条要点。
2. **回忆**：合上资料，画流程或回答问题，再对照纠错。
3. **应用**：把本周方法用到同一个练习项目，产生可检查成果。
4. **讲解**：用10分钟向“完全不了解的人”解释本周内容，并记录讲不清的地方。

学习不是以“读完49页”为完成门。每周必须留下一个成果，八周结束时应形成一份完整的项目管理档案。

## 5. 选择练习项目

选一个规模适中的项目，满足以下条件：

- 目标能在6—12周内描述清楚。
- 至少涉及2名角色，或者可以模拟发起人、项目经理和生产团队。
- 有3—8个可交付成果。
- 存在真实风险、干系人和取舍。
- 可以在学习期间完成至少一次周周期和一次月周期模拟。

可以用“小型网站上线”“课程学习与作品交付”“家庭空间改造”或“开源工具发布”作为练习项目。若选择Chat项目，只把本材料作为学习演练，不直接改写Chat当前权威计划和治理状态。

## 6. 学习纪律

- 先理解目的，再记步骤；这本身就是NUP5。
- 所有模板只保留能产生价值的字段，避免为了“填满模板”制造文档。
- 每次练习都记录一个“采用、改造、不采用”判断。
- 不把P3.express当成唯一真理；NUP1要求根据事实和结果持续修正理解。
- 不只练启动，必须练项目结尾和收益评估；否则没有形成完整闭环。
