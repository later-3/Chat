# OMIMO 掌握度测验参考答案与评分标准

## 1. A部分参考答案

每题2分：核心要点完整得2分，方向正确但缺关键边界得1分，错误或空白得0分。

1. 开放、极简、模块化。
2. 任务管理、团队管理、项目管理、项目群管理、项目组合管理。
3. 通用/领域专用、自由/专有、极简/极繁、路线图/建议。
4. 路线图提供可直接遵循的路径；指南主要提供建议。先用路线图建立可运行系统，再用指南丰富。
5. 提供跨方法、跨项目都值得遵守的原则，用于检查决定和管理活动是否仍有效。
6. NUP1结果与事实比隶属关系更重要；NUP2将精力和资源用在最重要的事情上；NUP3始终积极主动；NUP4细节决定成败；NUP5先定目标，后行动；NUP6使用可重复的元素。
7. 可以有偏好并选择方法，但不能把方法变成身份；新事实和结果应能改变判断。
8. 有限资源优先覆盖高价值部分，避免为不重要决定消耗认知精力，把精力留给高影响判断。
9. 不确定性改变规划的粒度和频率，不消除规划；自适应项目仍需一般准备、短周期计划和持续修订。
10. 方法元素相互依赖；脱离原系统后可能不兼容。应从完整方法剪裁，并检查整体一致性。
11. 比较“做/不做这件事”的两个世界，明确差异、受益者和价值，再判断是否值得成本。
12. 检查单、工作流/流程、日周月周期、方法都可。风险是流程过重、机械执行或未经剪裁无法适应现实。
13. 7个活动组、33项管理活动。
14. 发起人对最终结果、高层决定和资源负责；项目经理负责日常协调、团队环境和管理活动。
15. 项目经理管理项目整体；团队负责人领导内部生产团队和技术/生产工作。
16. 项目说明书、可交付成果导图、跟进登记表、运行登记表。
17. 可交付成果是要得到的产品或结果，名词能帮助团队避免把工作活动误当成范围与完成事实。
18. 决定项目是否值得批准并正式投入。否决不合理项目能避免损失，是有效项目组合治理。
19. 两者都检查项目是否仍合理；A08发生在首次启动承诺前，B03依据更新计划每月重新判断继续、终止或调整。
20. C01衡量并预测绩效、向干系人报告；C02在偏差出现时形成可执行纠正方案，必要时修改目标或取消项目。
21. 不在C03重复绩效衡量，也不在会议中临时详细规划风险/问题应对；前者属于C01，后者由持续的D01跟进流程处理。
22. 提供一个可随时访问、不会遗忘的统一入口，并把事项分配给管理员持续关闭；三种事项的状态和处置仍需区分。
23. 多个几乎完成的成果会制造在制品、浪费和不确定性；只有完整满足标准才是真正可接受的成果。
24. E01匿名收集满意度；E02结合反馈和教训形成有人负责的改进；E03传播本月成果并感谢贡献，保持目标一致与团队凝聚。
25. F完成移交、评审、归档、庆祝和正式结束；G在项目结束后评估、提高并沟通真实收益。

说明：官方中文C03页面的“常见问题”把风险应对链接到D02，但D02正文是“接受完成的可交付成果”，D01正文才负责风险、问题和变更请求。本学习材料依据活动实际内容按D01理解，并保留原归档不改写。

## 2. B部分评分标准

每题6分：识别问题1分，关联原则/活动2分，动作2分，解释后果1分。

### 情境1

- 问题：用方法隶属关系替代事实判断，消耗团队精力。
- 关联：NUP1为主，兼有NUP2、NUP4和NUP5。
- 动作：暂停阵营争论，列出项目事实和目标；比较不同方法对不确定性、合规、反馈周期和能力的适配；选一个完整基线再剪裁。
- 关键理由：没有“敏捷对瀑布”的宗教战争，只有针对具体环境的更合适选择。

### 情境2

- 问题：沉没成本、机械批准、项目理由已失效。
- 关联：NUP1、NUP3、NUP5；P3 B01、B02、B03。
- 动作：更新收益、市场和预测；做独立同行评审；让发起人明确重新决定继续、调整、暂停或终止。
- 关键理由：取消不再合理的项目是避免进一步损失，不是承认过去全部失败。

### 情境3

- 问题：在制品过多、假完成、管理层用标签替代事实。
- 关联：NUP1、NUP2、NUP5；P3 C03、D02。
- 动作：限制并行成果；优先完成少量高价值项；按明确质量标准逐项验收，未满足的保持未完成并公开阻塞。
- 关键理由：表面进度会掩盖真实交付风险并降低可预测性。

### 情境4

- 问题：报告没有服务决策目的，衡量投入而非预测结果。
- 关联：NUP2、NUP5、NUP6；P3 C01。
- 动作：先确定收件人要做的决定；把报告缩为一页，突出完成时间/成本/质量预测、目标偏差、风险和所需行动；确认干系人确实理解。
- 关键理由：工时等历史数据只有在帮助预测和行动时才有价值。

### 情境5

- 问题：把产品交付误认为收益实现，项目后责任缺失。
- 关联：NUP3、NUP5；P3 G01—G03。
- 动作：由发起人监督收益评估；检查预期、意外、潜在收益和损失；形成提升采用率的可执行行动、新项目或运营任务；设定复核并沟通。
- 关键理由：项目目的是产生收益，G组正是为产品移交后的收益闭环而设。

## 3. C部分评分标准

每项4分：

- 4分：内容完整、引用真实事实、有版本/决定/负责人/验收证据，并说明剪裁理由。
- 3分：主要内容完整，但缺少一项证据或边界。
- 2分：有结构和部分真实内容，仍以空泛描述或模板填充为主。
- 1分：只列标题或勾选，没有可验证内容。
- 0分：未提交。

## 4. 总分解释

| 分数 | 判断 | 下一步 |
|---|---|---|
| 90—100 | 已达到L3，接近L4 | 用第二个不同类型项目验证迁移和剪裁能力 |
| 80—89 | 达到L3基础 | 针对错题补原文，并强化结尾和收益管理 |
| 65—79 | L2为主 | 重做对应周练习，重点补项目证据而不是重抄笔记 |
| 0—64 | 尚未形成完整心智模型 | 从知识地图与NUPP重新开始，先掌握目的与结构 |

无论分数多高，如果无法完成结业口试、无法说明剪裁代价或没有真实项目证据，都只能视为“知识识别”，不能视为已经掌握。
