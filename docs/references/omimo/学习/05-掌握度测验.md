# OMIMO 掌握度测验

## 1. 规则

- 总分100分，建议限时90分钟。
- 前50分闭卷完成；情境题和项目证据题可以查看自己的工作簿，但不要查看参考答案。
- 80分为掌握线；低于80分时按错题对应的原文重新学习后再测。

## 3. B部分：情境判断（5题×6分＝30分）

每题写出：问题、相关NUPP/P3活动、建议动作、为什么。

### 情境1：方法阵营

两个团队争论“真正的专业团队只能敏捷”与“只有预测型计划才算项目管理”，讨论持续两周，却没有比较项目的不确定性、法规、交付节奏和团队能力。你如何处理？

### 情境2：机械批准

一个项目最初合理，但市场已经变化。每月B03仍由发起人直接批准，因为“已经投入这么多，不继续就浪费”。你如何处理？

### 情境3：几乎完成

团队同时推进12个成果，其中8个都声称完成90%，但没有一个满足完整验收标准。管理层要求把它们标为完成以让进度好看。你如何处理？

### 情境4：没人看的报告

项目经理每周制作15页状态报告，列出所有人花费的小时数。干系人几乎不阅读，也无法回答预计何时完成、还需要多少钱。你如何重设计？

### 情境5：交付成功、收益失败

产品按时移交，项目团队已解散。三个月后，产品采用率很低，预期收益没有出现。组织认为“项目已经关闭，没人负责”。你如何处理？

## 4. C部分：项目证据（20分）

使用你的[P3.express项目实践工作簿](03-P3.express项目实践工作簿.md)，提交以下证据：

1. 角色与项目说明书（4分）。
2. 可交付成果导图及完成标准（4分）。
3. 跟进登记表与至少2项可执行应对（4分）。
4. 一次周/月周期模拟及其预测、决定和沟通（4分）。
5. 项目结尾与项目后收益计划，包含至少1项剪裁决定（4分）。

## 5. 结业口试

在15分钟内完成：

1. 3分钟：解释OMIMO、NUPP、P3.express三者关系。
2. 4分钟：画出7组33项活动的循环。
3. 4分钟：展示练习项目的一次关键决定如何经过NUPP检查。
4. 4分钟：说明你对P3.express采用、改造和不采用的内容及原因。

口试不单独计入100分，但无法解释“为什么”时，不应把笔试高分视为真正掌握。
