# OMIMO 八周学习计划

## 1. 总体安排

- 周期：8周。
- 投入：每周4次，每次45—60分钟，总计约28—32小时。
- 主线：始终使用同一个练习项目，把每周知识转化为项目成果。
- 完成标准：测验不低于80分，工作簿完整，能够用15分钟讲清方法并回答追问。

如果时间紧，可以把每周压缩为2次90分钟，但不要删除回忆练习、真实应用和结业项目。

## 2. 开始前的基线测试

不查资料，用15分钟回答：

1. 项目、项目群、项目组合有什么区别？
2. 你通常怎样判断一个项目是否值得继续？
3. 风险、问题和变更请求是否应该放在同一个管理入口？为什么？
4. “项目交付完成”和“项目收益实现”有什么区别？
5. 你目前怎样组织每日、每周和每月的项目管理活动？

保留答案。第8周重新回答并比较，重点观察你的判断结构是否发生变化，而不只是术语变多。

## 3. 每周计划

### 第1周：认识OMIMO并学会选择方法

目标：解释OMIMO的定位，并用4个维度比较管理资源。

阅读：

- [OMIMO首页](../omimo.org/zh-hans/index/index.md)
- [模块全景图](../omimo.org/zh-hans/modules/landscape/index.md)
- [通用与领域专用](../omimo.org/zh-hans/modules/landscape/general-vs-domain-specific/index.md)
- [自由与专有](../omimo.org/zh-hans/modules/landscape/libre-vs-proprietary/index.md)
- [极简与极繁](../omimo.org/zh-hans/modules/landscape/minimalist-vs-maximalist/index.md)
- [路线图与建议](../omimo.org/zh-hans/modules/landscape/roadmap-vs-advice/index.md)

4次学习：

1. 读原文，画出项目生态的5个层级：任务、团队、项目、项目群、项目组合。
2. 合上资料，复述4个选择维度并各举1个例子。
3. 选择3种你接触过的管理资源，按4维度做比较。
4. 写一页“为什么本次先学P3.express”的选择说明，同时写出它不能解决什么。

本周成果：一份方法选择备忘录。

过关标准：不看资料说明“路线图”和“建议”的差别，以及为什么极简路线图适合作为执行起点。

### 第2周：NUPP 1—3——事实、聚焦与主动

目标：从方法阵营转向结果，从忙碌转向重点，从救火转向预防。

阅读：

- [NUPP简介](../omimo.org/zh-hans/modules/nupp/manual/v1/index.md)
- [NUP1](../omimo.org/zh-hans/modules/nupp/manual/v1/nup1/index.md)
- [NUP2](../omimo.org/zh-hans/modules/nupp/manual/v1/nup2/index.md)
- [NUP3](../omimo.org/zh-hans/modules/nupp/manual/v1/nup3/index.md)

4次学习：

1. 找出自己曾经“保护方法/团队身份而不是结果”的1个案例。
2. 盘点练习项目的资源，把事项分成最重要、必要、可推迟、应删除4类。
3. 列出5个风险，至少为前2个定义负责人和可执行应对措施。
4. 做一次10分钟Teach-back：为什么敏捷项目也需要规划？

本周成果：优先级清单、风险初表、1页复盘。

过关标准：能区分风险与问题，并为一条模糊应对措施改写出负责人、动作和检查条件。

### 第3周：NUPP 4—6——整体、目的与复用

目标：建立系统视角，让所有活动服务明确目的，并把有效做法变成可重复元素。

阅读：

- [NUP4](../omimo.org/zh-hans/modules/nupp/manual/v1/nup4/index.md)
- [NUP5](../omimo.org/zh-hans/modules/nupp/manual/v1/nup5/index.md)
- [NUP6](../omimo.org/zh-hans/modules/nupp/manual/v1/nup6/index.md)

4次学习：

1. 画出练习项目的目标、收益、可交付成果、时间、成本、质量、团队和风险之间的关系。
2. 审查当前会议和文档：为每一项写出目的，删除或合并没有明确目的的项。
3. 创建一份可交付成果“完成检查单”。
4. 用[NUPP决策检查卡](04-NUPP决策检查卡.md)审查一次真实决定。

本周成果：项目整体关系图、活动目的清单、可复用检查单。

过关标准：能解释“剪裁”不等于随意拼接，并说清怎样保护方法内部一致性。

### 第4周：P3.express基础与A项目启动

目标：能建立角色、描述项目、分解成果、规划风险并完成启动决定。

阅读：

- [P3.express概览](../omimo.org/zh-hans/modules/p3.express/index.md)
- [P3.express手册简介](../omimo.org/zh-hans/modules/p3.express/manual/v2/index.md)
- [A01—A10](../omimo.org/zh-hans/modules/p3.express/manual/v2/a/01/index.md)

4次学习：

1. 理清发起人、项目经理、团队负责人和生产团队的差别，为练习项目分配角色。
2. 填写项目说明书：目标/收益、成本/持续时间、要求/质量、范围、干系人。
3. 画3—8个可交付成果的层级导图，并建立首批风险应对。
4. 模拟A07同行评审与A08批准/否决会议，记录理由，再设计A09/A10启动沟通。

本周成果：启动包，包括角色表、项目说明书、成果导图、风险表、启动决定和沟通稿。

过关标准：能说明为什么项目经理不应同时承担主要技术生产工作，以及为什么否决项目可以是成功治理。

### 第5周：B每月启动与C每周启动

目标：用不同时间尺度持续修订计划、预测偏差和协调团队。

阅读：

- [B01—B05](../omimo.org/zh-hans/modules/p3.express/manual/v2/b/01/index.md)
- [C01—C04](../omimo.org/zh-hans/modules/p3.express/manual/v2/c/01/index.md)

4次学习：

1. 依据新信息更新整体计划和下月细节，不为远期内容制造虚假精度。
2. 完成一次月度同行评审，并重新作出批准/否决决定。
3. 设计一页绩效预测报告，重点回答预计完成时间、成本和目标偏差，而不是只列历史工作量。
4. 模拟一次周启动：下周工作、风险/问题、在制品限制和重点沟通。

本周成果：月计划revision、月度决定、一页预测报告、周计划和简短沟通稿。

过关标准：能解释B03与A08的共同点和不同点；能区分C01绩效衡量、C02纠偏规划和C03周协调。

### 第6周：D每日管理与E每月结束

目标：建立持续的事项入口、真实完成门和基于反馈的改进循环。

阅读：

- [D01—D02](../omimo.org/zh-hans/modules/p3.express/manual/v2/d/01/index.md)
- [E01—E03](../omimo.org/zh-hans/modules/p3.express/manual/v2/e/01/index.md)

4次学习：

1. 在跟进登记表中分别记录风险、问题和变更请求，为每项指定管理员和关闭条件。
2. 选择一个可交付成果，用“全部完成”标准进行验收，拒绝90%完成的假完成。
3. 设计不超过8题的匿名满意度调查，考虑小样本暴露身份的风险。
4. 模拟E02改进研讨会，形成3项改进措施及管理员，再写E03成果感谢信息。

本周成果：跟进登记表、成果验收记录、满意度问卷、改进清单、沟通稿。

过关标准：能说明为什么“忙于救火”会继续制造问题，以及为什么团队满意度也是项目健康的一部分。

### 第7周：F项目结尾与G项目后管理

目标：正式结束项目、保存组织记忆，并把交付物连接到真实收益。

阅读：

- [F01—F06](../omimo.org/zh-hans/modules/p3.express/manual/v2/f/01/index.md)
- [G01—G03](../omimo.org/zh-hans/modules/p3.express/manual/v2/g/01/index.md)

4次学习：

1. 制作移交与最终审批清单，列出未完成但可移交支持团队的事项。
2. 做最终满意度评估和结尾同行评审，记录趋势而不只记录单次分数。
3. 设计归档结构、只读与授权规则，写庆祝和结束沟通稿。
4. 创建项目后收益登记：预期收益、意外收益、潜在收益、损失、额外行动和下一次复核时间。

本周成果：结尾包和收益实现计划。

过关标准：能解释为什么项目团队解散后，发起人仍需监督收益；能区分产品移交、项目结束和收益实现。

### 第8周：完整演练、测验与Teach-back

目标：把零散知识组合成可运行的管理系统，并证明自己能剪裁使用。

4次学习：

1. 复查[项目实践工作簿](03-P3.express项目实践工作簿.md)，补齐A—G全部证据。
2. 完成[掌握度测验](05-掌握度测验.md)，暂不看答案。
3. 对照[参考答案与评分标准](06-参考答案与评分标准.md)纠错；低于80分的部分重新读原文并重答。
4. 做15分钟结业讲解：4个选择维度、6项原则、7组33活动、项目剪裁和1个真实教训。

本周成果：完整项目档案、测验答案、错题记录和结业讲稿。

过关标准：测验≥80分；工作簿≥85%完整；讲解中能回答“为什么这样做”和“什么时候不这样做”。

## 4. 间隔复习规则

每个新知识点在以下时间进行无资料回忆：

- 学完后第1天：写出标题和核心目的。
- 第3天：举一个正例和一个反例。
- 第7天：应用到练习项目。
- 第14天：把它与相邻概念比较。

建议维护一张错题表，只记录“当时错误判断—正确规则—下一次如何识别”，不要抄整段原文。

## 5. 结业后的保持计划

- 每周：用NUPP检查卡审查1个真实决定。
- 每月：复盘一次B/E活动，检查计划合理性和团队反馈。
- 每个项目：至少执行A、F、G三组，防止只会启动和推进却不会结束与验证收益。
- 每季度：重新做一次20分钟闭卷心智图，确认方法仍服务结果，而不是变成机械仪式。
