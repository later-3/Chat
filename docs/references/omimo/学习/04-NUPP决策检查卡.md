# NUPP 决策检查卡

## 1. 60秒快速检查

每次准备召开会议、写文档、批准计划、变更范围或处理风险前，快速回答：

1. **NUP1 事实**：我依据的事实是什么？是否在保护某个阵营、身份或既有方案？
2. **NUP2 重点**：最稀缺的精力和资源是否投向最重要的事情？
3. **NUP3 主动**：现在能做什么来预防、暴露或降低未来问题？
4. **NUP4 整体**：这个决定对目标、范围、时间、成本、质量、人员和风险有什么连锁影响？
5. **NUP5 目的**：如果不做这件事，两个世界有什么差异？差异值得成本吗？
6. **NUP6 复用**：这是一次性例外，还是值得形成检查单、流程或周期？

有任意一项无法回答，就先暂停决定，补充事实或缩小动作。

## 2. 六项原则详卡

### NUP1：结果与事实比隶属关系更重要

检查问题：

- 反对的是一个想法，还是提出想法的人？
- 如果方案来自“另一派”，我是否仍会客观评估？
- 哪些新事实会让我改变当前结论？

危险信号：

- “我们一直用这个方法。”
- “真正的敏捷/瀑布/项目管理不这样做。”
- 用团队身份、资历或证书代替证据。

行动：

- 把人名和方法名从问题中暂时删除，只比较结果与约束。
- 写出支持与反对当前方案的最强证据。
- 设定需要重新评估决定的触发条件。

典型P3.express活动：A07、B02、F03同行评审。

### NUP2：将精力和资源用在最重要的事情上

检查问题：

- 当前最重要的1—3项结果是什么？
- 哪些决策、会议或字段正在消耗精力但不改变结果？
- 是否存在过多在制品、微观管理或不可持续加班？

危险信号：

- 所有事项都标为高优先级。
- 为获得最后少量收益投入巨大成本。
- 项目经理亲自承担大量技术工作和所有跟进行动。

行动：

- 限制同时进行的成果数量。
- 把跟进行动分配给更多团队成员。
- 删除、推迟或简化低价值活动。

典型P3.express活动：A01—A06、B01、D01、F04。

### NUP3：始终积极主动

检查问题：

- 哪个风险可以在变成问题前处理？
- 哪项坏消息需要立即透明沟通？
- 当前计划何处已经与现实不一致？

危险信号：

- “到时候再看。”
- 只处理已经发生的问题，不维护风险。
- 把失败归咎于权限、组织或其他团队，却没有在约束内推进改进。

行动：

- 明确角色、风险管理员和应对措施。
- 尽早调整计划，而不是等里程碑失败。
- 把坏消息与可选应对一起公开。

典型P3.express活动：A06、B01、C02、D01、E02、G01—G03。

### NUP4：细节决定成败

检查问题：

- 是否只优化了时间、成本、技术或流程中的一个方面？
- 方法中的各元素是否相互兼容？
- 最弱环节会不会让整体结果失效？

危险信号：

- 只看进度，不看质量、团队、收益或风险。
- 从多个方法挑选喜欢的元素，却不检查它们能否共同运行。
- 用流程代替人的协作，或用“重视人”否定必要流程。

行动：

- 画出目标、成果、约束、角色和风险的关系。
- 从一种完整方法开始剪裁，再谨慎添加外部元素。
- 对高影响改变做整体一致性复查。

典型P3.express活动：A03—A07、B01、C01—C04、E01—E03。

### NUP5：先定目标，后行动

检查问题：

- 这项活动要改变什么？谁将使用结果？
- 当前衡量是为了预测和行动，还是为了展示忙碌？
- 我们关注的是产品，还是产品最终要带来的收益？

危险信号：

- 因为模板有某字段就填写。
- 状态报告很长，但收件人不阅读。
- 项目交付了产品，就默认收益已经实现。

行动：

- 为每份文档、会议和指标写一句目的。
- 围绕最终目标建立低层目标和预测指标。
- 项目结束后继续评估收益。

典型P3.express活动：全部33项，尤其A04、A08、B03、C01、F01、G01。

### NUP6：使用可重复的元素

检查问题：

- 哪些检查、审批或沟通会重复发生？
- 能否把有效做法变成简单检查单或周期？
- 当前标准化是否正在帮助工作，还是形成官僚负担？

危险信号：

- 每个项目都重新发明流程和模板。
- 检查单过长，参与者只能机械勾选。
- 把模板当目的，不做必要剪裁。

行动：

- 从最小可复用清单开始。
- 使用日、周、月等周期降低记忆负担。
- 每个项目结束后更新可复用资产，但保留适用条件。

典型P3.express活动：四类管理文档、B/C/D/E周期、F04归档。

## 4. 每周复盘

每周只回答6题：

1. 本周哪次判断被事实纠正？
2. 哪项投入最有价值，哪项应停止？
3. 哪个问题本可更早预防？
4. 哪个被忽略的环节影响了整体？
5. 哪个活动失去了明确目的？
6. 哪个成功做法值得形成可复用元素？

每题至少形成一个下周动作；没有动作的复盘只是回顾，不是改进。
