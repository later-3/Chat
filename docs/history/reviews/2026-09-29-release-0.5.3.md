# 0.5.3 发布与会话记忆迁移、浮层统一核对

## 范围

用户要求更新版本。本轮不更新本机正式服务、不迁移正式数据，也不在空白 Linux 主机执行 systemd 安装。

Chat `0.5.2` → `0.5.3`；Frontend `0.11.0` → `0.12.0`。Pi 保持受管 Fork 的固定提交 `5b580155b`，基础包版本 `0.85.1`；NanoClaw 无修改，沿用 `c14d98d`。父仓库 `v0.5.3` 记录全部 gitlink。

## 变化与修复

- **会话记忆随会话存放**：`<存储根>/session-memory/<id>.json` → `<存储根>/sessions/session-memory/<id>.json`。读取回退旧路径，写入发布新路径并删除旧副本，purge 双删，启动迁移（`src/migrations/session-memory-layout.ts`）在同一存储根内 rename 并带 per-root 标记；目标已存在时不覆盖。回归：`test/long-agents/session-memory.test.mjs` 的读取/写入迁移与批量迁移用例，另有 `test/workflows/session-memory-tail.test.mjs` 的路径断言。
- **浮层统一**：所有浮层页面共用同一个 `SurfaceDialog`，**同一尺寸（`min(1120px, 100vw−48) × min(860px, 100dvh−48)`，居中）与同一位置**；删除了 `wide`/`full` 档位（本轮缺陷的根因就是"同组件不同档位"），只保留用户主动触发的 `maximized`。新增 `SurfaceSheet`（底部动作面板：同遮罩/同层级/同 Token 动效，只有位置不同）。手写模态从 12 个收敛到 1 个（命令面板例外）；嵌套记忆编辑器改为嵌套 `SurfaceDialog`；iOS 安全区内边距从"仅扩展对话框"移到共享遮罩。门禁：尺寸唯一、层级必须用 `--layer-*`、无私有 keyframes、sheet 契约、禁止调用方传尺寸。
- **输入区与顶栏**：输入框为框内**单行**（textarea + 附件 + Workflow + Agents + 发送/停止），Workflow 选择器为"图标 + 名称"并使用共享菜单；会话记忆（带计数）、压缩、声音、推送移入会话顶栏；会话记忆徽标由接口驱动、轮次结束即刷新。
- **开发体验**：`components/ChatInput.tsx` 只导出组件，恢复 Vite Fast Refresh；此前 composer 改动必须手动刷新。
