# Frontend 全面更新交付记录

日期：2026-09-27。范围：此前盘点的 30 个任务区域及其共用控件。实现位于 `codex/unified-session-performance` 未提交工作区；未提交、推送或部署生产。

## 结果与设计方向

主要开源参考仍是 **LobeHub、Cherry Studio**。本次采用温暖中性色、墨色正文和克制紫色强调，建立自己的统一外观。Google 的布局、Adobe 的交互状态、Microsoft 的语义颜色、Apple 的触控与可读性、Meta 的可访问性分别作为规则依据；不将几套产品皮肤混搭。权威规范为 [Frontend UI/UX v2.0](../../../frontend/docs/ui-ux-guidelines.md)，实现职责见 [Frontend 开发](../../../frontend/docs/development.md)。

处理顺序为功能事实、交互路径、视觉呈现。原审计 17 个 P1/P2 区域均已有对应整改；这是整改范围的闭环，不表示 30 个区域的全部状态都已经人工验收，更不把“一流软件”当作一次测试可以颁发的等级。保留原有清楚的列表—详情、阅读器和设备流程，通过统一基础样式与局部修正接入规范，没有为追求改动数量重复实现。

## 主要行为变化

1. **日期工作区**：点击日期直接进入当天，URL、当前会话、当天工作列表一致；跨日实际有活动的同一工作允许出现两天，身份按 workId 区分。同标题工作不合并。历史周期任务优先显示可读摘要和开始时间，稳定 ID 可追溯。
2. **模型与思考**：可搜索模型名称/Provider/ID，认证不可用的模型明确禁用；后端从 Pi 提供每个模型的可用等级，前端不猜。思考使用带解释的单选组；继承和显式选择分别表达。Provider/模型规格/价格/高级兼容设置分层，窄屏列表与详情切换。
3. **群聊**：只保留一个聊天工作区，管理页负责成员与权限；一个历史菜单容纳公开与成员记录。发布消息和开始讨论明确说明。草稿按群隔离；重复点击、丢失回执后重试复用稳定请求 ID，确认不能清掉用户后来输入的草稿。断线重新订阅并轮询补齐，撤销访问停止观察。“不再重试”只丢弃本机待核对请求，不取消可能已接受的服务端工作；停止工作使用已有取消动作。
4. **设置与资源**：设置类别、项目范围进入 URL；外观、语言、内容宽度显示全部明确选项。Friend 管理改纵向栏目，Prompt/工具/技能/资源/渠道按需展开，群/主题进入对应工作区；任务与职责读取失败不伪装空集。Memory 搜索有标签，维护操作下沉。技能目录的 6 类点击结构改为原生按钮，可用键盘选择/展开。
5. **共享会话与主题**：记忆入口归入输入工具栏，主题节点的开关通过既有 PATCH/revision 保存，主题地图、日期和直接会话链接都从同一服务端策略恢复；加载失败可重试，不展示假定的默认勾选。普通会话保留现有每会话开关。编辑冲突保留草稿并读回新版本。节点策略更新不卸载当前会话或关闭记忆弹层。日期、列表和底部布局沿用前序修复。

## 追加：中英文界面一致性

用户确认默认英语，设置可切换英语/简体中文。本次补齐并校验 **1,920 个双语词条**：导航、模型与思考配置、资源与工作流配置、占位说明、运行状态、错误摘要、无障碍标签、日期数字、完整历史阅读控件及离线页面。8 个内置工作流的默认名称、说明与节点/智能体标签按 ID 和原始默认文案翻译；自定义名称和内容不改写。

语言偏好首屏读取 `pi-locale`；不再依浏览器语言自动选择中文。两种语言即时切换，刷新后保留；非法值和存储不可用均回到英语。错误信息提供本地化摘要与可展开的原始诊断。资源/会话正文、模型/服务商名称、协议名称、路径、ID 与原始日志是内容边界，保留原值。独立下载的原始 Pi 导出保留上游格式；Chat 内的阅读器控件跟随界面语言。
