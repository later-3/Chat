# Friend 任务导航与共用交互验收

日期：2026-09-27。基线：`codex/unified-session-performance` 未提交工作区。用户确认的六项产品调整，设计入口见 [任务与导航计划](../../development/friend-task-navigation-plan.md)，视觉/行为标准见 [Frontend UI/UX 规范](../../../frontend/docs/ui-ux-guidelines.md)。正式数据和生产服务未改动。

## 交付范围

1. 助手管理由 9 个栏目收敛为 4 个：助手设置、定时任务、长期任务、助手记忆。Nano 身份/长期指令进入助手设置；用量汇总是次级概览。群聊、朋友圈、主题用全局入口，不再在助手管理复制。
2. 定时任务与长期任务内查看属于它们的成果，后台任务可查看对应 Session 累计用量与成果。关联只认 taskId/dutyId/workId；任务可有多次执行和多项成果，不按名称或日期猜测。已登记笔记/动态的补交、版本、冲突和通知操作保留。普通文件写入仍在原会话工具记录中，不能伪装为已登记成果。
3. 群公共会话与成员参与记录是不同的原生 Session，每个存储归属唯一。历史导航优先使用后端 `groupConversation`，回到原群；深链规范化后刷新仍留在群，成员完整历史仍可阅读。
4. 设置、朋友圈、群聊、主题及助手管理共用左侧 `PageHeader/BackButton`。全局“返回交流”回到保留的交流，浏览器后退继续遵循历史；助手设置的返回关闭管理面，保留原页面。
5. Friend 与群后台任务移除名称/说明创建表单。对话入口聚焦相应输入框，由已授权 Agent Tool 创建。保留旧未确认请求的同 ID 重试和已有任务的停止。侧栏日常对话不重复标题，同日刷新不清空列表；无法确认执行状态时不误写为创建失败。
6. `Button` 已接入 26 个组件、106 个调用位置；Dialog 和确认分别接入固定版本 Radix Dialog/AlertDialog。共享主题、焦点、Escape、禁用和移动尺寸；列表项保留选择语义。旧复杂编辑容器仍保留业务草稿保护，通过焦点 Hook 与嵌套公共 Dialog 协作。手机长通知改为限宽换行。

## 修复的实际缺陷

- 长期任务预算、助手汇总漏算 Pi compaction/branch_summary 用量。统一读取原生 usage，累计 input/output/cacheRead/cacheWrite；同 turn 多个状态标记不能提前截断，后续不同 turn 不归入前一执行。
- 助手汇总误用服务器时区。采用 Friend 持久化时区，后端决定默认 14 日窗口；响应包含 timeZone，前端验证整条统计结构。
- 旧群记录按执行者误导航、日期侧栏同日刷新清空、窄屏通知横向截断，分别补上对应浏览器回归/截图检查。
