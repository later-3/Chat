## 最终收尾复核（2026-09-21）

本轮直接复核新增预算、V9/V11/V12 和浏览器组合，并修复计量失败的收尾问题。最新验收结论见本文顶部；之前各轮的未验收状态保留作为历史，不能覆盖最终结论。

### 直接补强

- 原 Token 记录调用为异步发起并忽略失败。本轮改为可等待的串行记录链，下一次 provider 请求与最终发布前均等待持久化；计量失败则拒绝续轮和结果发布。Pi 同步事件回调仍保持非阻塞，没有另建模型循环。
- 新增两条真正执行的故障注入：讨论/独立 user work 的用量写入发生 EIO，实际模型请求停在 1 次且公共投影不出现结果。执行协议永久门禁现在 16 项。
- 浏览器扩大到两群五策略后，恢复原有刷新历史门禁，避免覆盖范围倒退。
