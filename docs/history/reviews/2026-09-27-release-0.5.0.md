# 0.5.0 发布与 Linux 交付核对

## 范围

用户授权版本更新、提交和推送，并准备新 Linux 的 release 服务与 VS Code 调试启停。本轮不更新本机正式服务、不迁移正式数据。

Chat 0.4.0 → 0.5.0；Frontend 0.8.12 → 0.9.1。Pi 的摘要请求准入、取消及统计修改按受管源码提交固定，保持基础包版本 0.85.1，不执行独立 npm 发布；NanoClaw 无修改。父仓库 `v0.5.0` 记录所有 gitlink。

## 对齐与修复

- 安装入口与源码固定到同一标签；release `/opt/chat` 与用户开发 checkout 分开，端口、Chat Home、Nano 数据及关闭范围明确。
- README 删除过期的每项目 Friend 主会话及 Web 密码说明；调试地图改为新轮次的接受记录 → Workflow → 公共 Pi 装配，保留旧阻塞接口说明。
- CI 文档纠正“尚未接入 NanoClaw”；区别 Gateway/Channel 合同夹具与真实 Nano Host。
- CDP 从仅 macOS 路径扩展到 Linux PATH 和显式 `CHROME_BIN`；错误显式路径失败，CI 缺浏览器失败。纯服务器未安装浏览器时显示跳过，不能声称浏览器验收通过。
- 首次 Ubuntu 干净检出发现 UI 审计的 5 个截图链接依赖本机忽略目录，已改成仅本机证据索引；没有上传含用户历史的截图，也没有放宽文档链接检查。
- Pi 既有完整检查中的 11 处模型引用类型错误已修复：Gateway 的 Workers AI 测试使用明确的协议夹具，Copilot live 测试使用固定目录现存模型；历史回放保持原模型 ID，生产模型目录不修改。另修复自定义 Gateway Completions 模型未被目录列出时绕过 Provider 认证/地址解析的问题。
- Pi 全量 Ubuntu CI 另外发现 2 处旧队列测试在异步输入处理完成前检查数量；测试改为等待 `steer()` / `followUp()` 完成，并验证队列消息内容。该修正只涉及测试和变更记录，没有改变运行时接口。
- Ubuntu 调试启停回归暴露了僵尸进程组被误判为存活的问题；进程组探针统一排除 Z 状态，保留归属与权限检查，失败测试清理也增加暂停恢复和有界强制退出，见[案例](../../development/experiences/linux-debug-zombie-process-groups.md)。
