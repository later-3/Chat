# LA2：Friend 创建复验、任务定义与调度验收

2026-09-20。范围来自 [LA 阶段计划](../../development/long-agent-functionality-plan.md) 的 LA2，以及本轮要求的创建 Friend 真实浏览器复验。实现合同统一保存在 [Friend 任务](../../modules/long-agents/tasks.md)，本文只记证据、发现和边界。未提交、推送或部署正式服务。

## 交付及发现

1. 创建 Friend 只填写名称与可选简介，系统生成内部 ID。原 `36145` 是连接离线 `45999` Host 的 UI 演示进程；正式 `43110` 与 Nano `3000` 的只读检查显示网关可用，不能从演示页推断正式创建链路故障。前次 LA1 测了已有 Friend 的后台工作，没有覆盖新建入口；本轮补齐。
2. 创建错误分别说明连接不可达、缺少认证、认证不匹配、接口版本/实例冲突，不再给所有失败同一句含糊提示。真实浏览器经历断线失败、保留草稿、恢复 Host、原请求成功、刷新仍在及进入日常会话。
3. Task API v2、注册的 `task_manage` Tool 和 Web 使用同一个定义服务；原 Nano 任务代理、隐藏默认任务补齐器及旧前端协议已删除。Nano 保存版本化调度投影和耐久触发 Outbox，不执行模型。
4. 一次性、cron、可信事件；创建、编辑、暂停、恢复、取消未来安排、立即运行、取消某次、历史/结果链接均已接入。Occurrence 与 LA1 work/turn 区分，工作在独立原生 Session 中执行。
5. 浏览器发现任务表单误复用了设置页固定底栏，旧任务按钮遮挡“保存”。已改为表单/任务行内操作，桌面实际点击保存通过；390px 屏幕保存按钮命中检测无遮挡、无横向溢出。旧“名称可选/周期可选”标签也已校正。
6. 自检发现旧 `task-scheduling` Skill 仍教 Agent 调用旧 `recurrence/processAfter/delete` 参数。已同步同源定义、修订、触发类型、取消范围及幂等语义，普通 Personal Skill 更新仍保留用户自定义副本。

## 真实浏览器与模型

使用 Playwright 控制真实 Google Chrome，独立 Backend `39159`、Nano Gateway `39158`、独立 Chat Home/Nano DB。Nano 使用真实 Group 初始化、资源 API、SQLite 迁移、调度与转发模块，不伪造创建/任务响应。不是完整 Host 安装/升级或真实 Telegram 收发验收；初次完整 Host 在无 Git 元数据的临时目录被原生升级保护拒绝后，没有关闭该保护，改用原生模块组成的隔离验收进程。

## 阶段自检

| 检查 | 结论和限制 |
|---|---|
| 是否只做模型/页面样例 | 否。真实管理 UI、注册 Tool、触发投影、持久发生、独立执行、结果查询一起交付 |
| 是否形成第二套运行时 | 否。Nano 没有 Agent Loop；Task 引用 LA1 AcceptedTurn/Pi，不把 Workflow Session 当另一份模型历史 |
| 是否有双调度所有者 | 已通过 owner 领取、不可变快照、旧 writer/forwarder 拒绝和单调修订约束；旧执行不静默重放 |
| 是否冻结正确事实 | 发生时冻结 Task 文本/项目/策略；获得容量接受工作时冻结 Agent 装配，二者时点已明确。网页切项目不改任务目标 |
| 是否夸大 exactly-once | 否。接受/重投使用稳定身份；模型或工具结果未知时记录中断，显式新运行可能再次产生副作用，不能自动重放来冒充恢复 |
| 是否遗漏异常与可用性 | 补齐脚本迁移暂停、过期一次性迁移待确认、排队取消、容量竞争、断网重试、遮挡按钮、错误文案、无效时区/cron 的可修正 400 与旧 Skill 合同 |
| 是否偏离最终目标 | 否。LA2 只是具体任务和触发；长期职责自主分解、学习进度、心跳、3+1 产物协议及群聊仍由 LA3–LA5 完成 |

明确边界：每个 Friend 同时最多 4 项后台工作；每条 cron 沿用每日最多 4 次限制；调度约每分钟扫描。事件来源需真实服务接入，不自带文件/网站监视器。Task 历史和修订保留，当前没有归档/保留期 UI。外部渠道、Docker、WSL/Linux 安装和持续 24 小时运行本轮未测。未把这些范围伪装成 LA2 完成内容。
