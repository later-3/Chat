# Frontend 全面更新工作记录

状态：实现与最终完整验证完成。开始于 2026-09-27。范围由用户授权为全部 Frontend，包括页面、局部选择、配置、浮层、状态和文档，不限于审计的 17 个问题区域。

## 场景、机制与责任

用户在同一工作台中与 Friend / 项目 / 群 / 主题交流，选择模型与思考等级，管理资源，并能理解当前对象、动作后果与恢复路径。正常选择必须立即可见；慢请求、断线、快速切换、重复点击不得错对象、清掉新草稿或伪造空列表。

此次复用 Backend 配置目录、现有领域 API、公共 Session 展示与 Pi 执行链。Frontend 仅拥有导航、草稿和临时交互。视觉规范仍由 `frontend/docs/ui-ux-guidelines.md` 唯一维护；本文只记录范围、实现顺序与证据。LobeHub / Cherry Studio 是布局参考，不引入它们的运行时。

## 交付顺序

1. 共用基础：语义色、排版、表面、焦点、控件、可搜索选择、模型与思考等级。
2. 六个全局入口：Friend、项目、动态、群聊、主题、设置；导航恢复和窄屏单任务面。
3. Friend 九类管理内容、模型 Provider、Memory、Tools、Skills、Prompt、Plugins、Extensions。
4. 共享区域：日历、后台工作、会话记忆、Workflow 配置、历史/分支/统计、文件/图像、目录与移除区、设备/离线/诊断。
5. 文档、场景回归、明暗主题/代表视口检查及完整 `pnpm verify`。
