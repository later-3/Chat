# Friend 任务与导航统一

2026-09-27，用户已确认的产品调整；已完成本地实施与验收。证据见 [任务导航验收](../history/reviews/2026-09-27-friend-task-navigation.md)。

## 产品合同

- 长期任务是持续目标（内部 Duty），定时任务是触发安排（内部 Task），后台任务是一次独立执行（Work）。后台任务由用户与 Agent 对话，调用已有 `friend_work` 创建；侧栏负责查看、继续与停止，不另填创建表单。
- 任务成果依附来源：长期任务 → 定时任务 → 一次发生/后台执行 → 零个或多个成果。沿用已有 dutyId/taskId/occurrenceId/workId，历史版本不形成新的孤立产物。独立日常对话和朋友圈可存在，不将一切交流强制伪造成任务。
- 用量属于真实 Session/执行；任务汇总其关联执行，助手日期汇总属于统计视图，不能当作额外执行实体。包含 Pi 持久化的摘要用量，使用 Friend 时区归日。
- 助手设置保留配置、长期任务、定时任务、助手记忆；Nano Agent Group 的身份/长期指令并入配置。移除“职责、交付、活动、智能体组”顶层栏目；朋友圈、群聊、主题走现有全局入口。
- Session 存储身份唯一；群公共会话与成员参与会话是不同 Session，以明确关系关联到同一群。群记录的导航优先使用 Backend `groupConversation`，不按执行助手切到私聊，也不改存储归属。
- 全局页左上使用同一返回组件，语义为回到保留的交流，不使用浏览器上一次任意操作冒充“返回交流”。浮层为关闭，编辑未保存必须保留确认。

## 组件实施

复用现有主题与 Tabler 图标；集中 Button、BackButton、PageHeader 与对话框基础组件。Dialog/确认使用 Radix 的焦点、Escape、可访问语义；业务层继续控制草稿与异步提交。选择、列表项不是主动作按钮，保留各自选中语义。新控件不逐页定义按钮外观。

## 验证

先落实导航/组件和双语术语，再修计量/时区。回归覆盖群列表/深链/刷新、返回目的地、聊天创建后台任务、任务成果过滤、实际原生压缩后的职责预算及跨时区统计。浏览器检查明暗、宽窄布局、焦点/关闭和表单消失；最后完整 `pnpm verify`。验证日志与截图存忽略目录，结果写历史验收文档。
