## 1. 怎样使用

```text
遇到高风险名称
-> 在本页按中文名、英文名或别名检索
-> 进入Chat作用域索引或概念簇正文
-> 需要产品责任时进入PROJECT_CONTEXT
-> 需要当前实现时进入PROJECT_STATE
-> 需要具体行为时进入源码、测试或协议规范
```

AI不应每次启动都读取全部概念，只读取当前任务涉及的概念簇。面向用户时仍要就地解释，不能要求用户先完成文档阅读。

## 4. 高频防混淆入口

| 用户说法 | 必须先判断 |
|---|---|
| 会话 / Session | Product Session、MAF AgentSession、AG-UI Thread、外部Channel Conversation还是Workflow Checkpoint？ |
| 工作流 / Workflow | 项目交付Workstream、可执行Workflow Definition、用户选择还是实际Run？ |
| Agent | 可编辑Profile、MAF运行对象、某个Executor还是整个产品？ |
| 继续 / 重来 | Follow-up、Steer、Retry、Restart还是Checkpoint Resume？ |
| Prompt | 输入框草稿、已提交User Message还是完整Provider Request？ |
| Tool | 已注册能力、模型可见定义、模型提议、已批准执行还是执行结果？ |
| Canvas | 布局类比、右侧Workbench、Workflow Run View还是持久化白板Artifact？ |

## 5. 生命周期和维护

本目录使用“候选、有效、修订中、已停用”四种概念状态。概念修改只在唯一正文发生，索引只同步导航字段。真实用户反馈、源码证据或协议变化推翻定义时，先标记“修订中”，再修正依赖它的UI、合同和文档。
