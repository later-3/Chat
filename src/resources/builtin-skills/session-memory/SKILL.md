# 会话记忆（Session memory）

会话记忆是**本会话**的耐久伴生物，用来把可跨会话复用的结论沉淀下来，供以后的主题节点整合复用。它不是长期个人记忆，也不写 NanoClaw memory。

## 什么时候写

只在本轮产生了**值得跨会话复用**的独立事实/结论时写：定位到的根因、确认的规则、可复用的经验、明确的目标或背景。过程性叙述、原文摘抄、能从代码直接读出的内容不要写。

## 怎么写

- 一条 = 一个独立事实/结论，一到几句话，能单独读懂。
- `purpose` 按语义归类；`author` 按语义来源标 `agent`（Agent 产出/提炼）或 `user`（用户发言及其浓缩）。
- **推翻旧结论用 `supersede`**，不要堆叠新条目。
- 写之前先 `list` 看既有条目；需要前文时用 `history` 按需读取。
- 写完后可见回复必须引用工具实际返回的 `entryId` 与 `revision`；没有可写内容就说"本轮无需写入"。
