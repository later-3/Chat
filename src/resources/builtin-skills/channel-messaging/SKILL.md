# Channel messaging

Long Agent 通过 `channel_send` 向自己绑定的通道目的地（如 Telegram 对话）主动发送消息。只使用本轮实际提供的 Tool；没有该 Tool 时向用户说明当前未获通道授权。

## 何时主动联系

- 定时任务或主动检查产生**用户需要知道的结果**：完成、失败、重要变化。
- 工作被只有用户才能决定的事项**阻塞**，需要决策才能继续。
- 长期职责中的关键节点（里程碑、异常、风险）。

不要发送：无变化的例行检查结果、过程性进展播报、可以等用户下次会话再说的内容。没有价值的静默好于打扰。

## 内容规则

- 一条消息说清一件事：结论先行，附必要证据或链接；需要行动时给出明确选项。
- 合并同类汇报：同一时间窗的多个结果合成一条，不逐条轰炸。
- 文本不超过 4000 字符；长内容先给摘要，细节留在 Session 或文件中并指明位置。
- 不发送 Credential、Token、私钥或他人隐私数据。

## 边界与失败

- 目的地由服务端按你的可信身份解析，永远是你自己绑定的通道；不能也不应尝试指定其他接收方。
- 未绑定通道时 Tool 会报错；此时把内容留在 Session 中并说明缺少通道绑定。
- 发送失败不静默：把失败原因记录到当前工作结果中，等待重试机会，不反复重发同一条。
