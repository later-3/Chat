# 前端会话面板的数据来源与保存形式

**归档日期**：2026-07-28
**分类**：Session与状态持久化
**关联源码**：
- `frontend/src/features/session/session-api.ts`（前端会话 REST 调用）
- `frontend/src/features/session/session-sidebar.tsx`（会话列表面板）
- `backend/app/product_sessions/database.py`（产品会话 SQLAlchemy 表模型）
- `backend/app/product_sessions/service.py`（ProductSessionService）
- `backend/app/workflows/checkpoints.py`（MAF Checkpoint 的产品级存储适配器）

## 问题

前端面板展示的会话，是我们自己在 MAF 里面保存的吗？是以什么形式保存的？

## 回答

**结论：不是。前端会话面板展示的是我们自己的 Product Session（产品领域事实），存在项目自己的 SQLite 数据库里，和 MAF 没有关系；MAF 的运行状态是另外单独保存的。** 这正是项目规则里"MAF 运行状态和产品领域状态分开持久化"的落地。

### 1. 前端面板的数据从哪来

链路是纯 REST 投影，不经过 MAF：

```text
session-sidebar.tsx（会话列表面板）
  ← App.tsx 里 setSessions(sessionList)
  ← session-api.ts 调 GET /api/sessions
  ← 后端 ProductSessionService
  ← SQLite：backend/.data/chat.db
```

浏览器端只是投影，不拥有权威状态（[session-api.ts](../../frontend/src/features/session/session-api.ts)）。

### 2. 以什么形式保存：SQLAlchemy 表，一个会话拆成多张关联表

[product_sessions/database.py](../../backend/app/product_sessions/database.py) 定义的核心表：

| 表 | 存什么 |
|---|---|
| `product_sessions` | 会话本体：标题（含来源）、状态、revision、渠道、模型配置、归档时间——**面板列表直接读这张** |
| `interactions` | 一次用户输入交互 |
| `product_runs` | 每轮 Product Run：状态、请求 Hash、关联的 ExecutionDraft/RunSpec/审批 ID |
| `run_attempts` | Run 的重试/接管尝试 |
| `product_messages` | 权威消息记录（打开会话看到的历史消息读这里） |
| `trace_events` | Trace 事件 |

### 3. MAF 那边单独存什么

MAF 自己的运行时状态（39 节点 Workflow 跑到哪、暂停在哪个审批点）以 **Workflow Checkpoint** 形式保存——但也不是 MAF 自带的文件存储，而是我们实现了 MAF 的 `CheckpointStorage` 接口写进同一个 SQLite 的**独立表** `maf_workflow_checkpoints`（[checkpoints.py](../../backend/app/workflows/checkpoints.py) 的 `ProductWorkflowCheckpointStorage`）：

- **MAF 拥有** checkpoint 的 payload 编码和恢复算法（我们只复用它的 JSON 编码器）
- **我们附加**产品侧绑定：checkpoint 必须绑定 Product Run ID、Run Attempt、workflow 版本和图签名 Hash，跨进程恢复时不匹配就拒绝（防止拿别的 Run 的 checkpoint 恢复）

### 4. 一句话区分（对应项目的四对象边界）

- **面板看到的会话/消息** = Product Session / Product Message，产品自己的事实源，SQLite 产品表
- **MAF 保存的** = 某一次 Run 的 Workflow 执行快照（checkpoint），只用于中断恢复，不是会话历史的来源
- 两者即使 ID 有关联也不混用：删掉全部 MAF checkpoint，会话列表和历史消息完好无损；反过来只有 checkpoint 也拼不出会话面板。
