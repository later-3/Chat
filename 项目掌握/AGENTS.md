# 项目掌握知识库 — AI Agent 协作规则

## 1. 目录职责

本目录是**用户掌握整个 Chat 项目的个人知识库**。每个与用户交流的 AI Agent 都必须：

1. 在回答问题前，先检查本目录是否已有相关归档。
2. 回答完成后，按本文件规定的结构归档到对应文档。
3. 如果已有文档覆盖了当前问题，直接引用并补充新发现，不重复创建。

## 2. 目录结构

```
项目掌握/
├── AGENTS.md          ← 本文件：Agent 协作规则
├── INDEX.md           ← 全局索引：按分类列出所有已归档问题
├── <分类文件夹>/
│   ├── <问题文档>.md  ← 一个问题一个文档
│   └── ...
└── ...
```

## 3. 命名规则

| 对象 | 规则 | 示例 |
|------|------|------|
| 分类文件夹 | 简短中文短语，描述问题领域 | `执行层与pi运行时` |
| 问题文档 | 简短中文问句或主题名 | `pi子进程在哪里启动.md` |

## 4. 问题文档格式

每个问题文档必须包含：

```markdown
# <问题标题>

**归档日期**：YYYY-MM-DD
**分类**：<分类文件夹名>
**关联源码**：<关键文件路径列表>

## 问题

<用户原始问题或精炼后的问题>

## 回答

<结构化的回答内容>

## 关键文件

| 文件 | 职责 |
|------|------|
| ... | ... |

## 补充记录

<后续对话中的补充、修正或新发现，按日期追加>
```

## 5. Agent 执行流程

1. **查重**：读取 `INDEX.md`，检查是否已有同类问题。
2. **引用**：如果已有文档，先读取内容，在此基础上补充而非重写。
3. **归档**：回答完成后，创建或更新对应文档。
4. **更新索引**：新增文档时，同步更新 `INDEX.md`。

## 6. 禁止事项

1. 不得把多个不相关问题合并到一个文档。
2. 不得在回答后忘记归档。
3. 不得修改已有文档的原始回答内容，只能追加补充记录。
